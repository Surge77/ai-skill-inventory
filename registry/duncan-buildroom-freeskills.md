## Installing one of these

```bash
git clone --depth 1 https://github.com/duncan-buildroom/freeskills.git /tmp/duncan-buildroom-freeskills
cp -r /tmp/duncan-buildroom-freeskills/<path-from-the-table-above> ~/.claude/skills/
```

Copy the whole skill directory, not just `SKILL.md` — the `Size` column counts sibling files, and a skill whose siblings are missing has dangling links. The upstream `npx skills@latest add duncan-buildroom/freeskills` installs the entire repo through a shared store; see [../reports/health.md](../reports/health.md) for why that store is avoided here.
