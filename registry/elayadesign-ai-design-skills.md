## Installing one of these

```bash
git clone --depth 1 https://github.com/elayadesign/ai-design-skills.git /tmp/elayadesign-ai-design-skills
cp -r /tmp/elayadesign-ai-design-skills/<path-from-the-table-above> ~/.claude/skills/
```

Copy the whole skill directory, not just `SKILL.md` — the `Size` column counts sibling files, and a skill whose siblings are missing has dangling links. The upstream `npx skills@latest add elayadesign/ai-design-skills` installs the entire repo through a shared store; see [../reports/health.md](../reports/health.md) for why that store is avoided here.
